# Swift & iOS Development

This repository contains topic-wise PDF notes for learning Swift programming and iOS application development.

## Topics Covered
- Swift Fundamentals and Collections
- Functions, Closures, Protocols and Generics
- Memory Management and Concurrency
- Networking and JSON Parsing
- UIKit and SwiftUI
- iOS Architecture and Lifecycle
- Xcode, Testing and Performance Analysis

## Learning Resources
Each topic is uploaded as a separate PDF for easy reference, learning, and revision.

## Goal
To develop Swift programming skills and learn iOS app development through structured notes and practical exercises.
